## Methodology in brief

1. **Six interest domains (NI-1–NI-6)** distill bipartisan NSS language: homeland, economic/tech, alliances, Indo-Pacific, rules/reciprocity, domestic sustainability.
2. **Orientation priors** (Pressure, Stabilization, Reframing) suggest which domains typically move first and on what horizon.
3. **National War College tier rubric** provides adjudication grammar: +2/−2 (vital), +1/−1 (major), 0 (peripheral) — applied sparingly at the vital level.
4. **Evidence base:** NSS Interest Matrix + National War College Primer; Clinton 1994 NSS is the historical engagement-era floor, not the default post-2017 lens.

This layer is **game-agnostic**. Fractured Order 2.0 application lives separately in the FO2.0 repo (`FO2.0_NI_Adjudication_Spec.md`).

## Using this package in Cursor (Composer 2.5)

1. Unzip this folder to a local path (e.g. `~/Projects/NI_Methodology_Share_Package`).
2. **File → Open Folder** in Cursor and select the unzipped directory.
3. Example prompts for Composer:
   - *"Summarize the six NI domains and when to use +2 vs +1 tier deltas."*
   - *"How does a Pressure orientation differ from Reframing in domain priors?"*
   - *"Explain the threat cross-check formula and when NI-3 matters despite positive NI-2."*
   - *"What changed in PRC framing across NSS eras in the matrix?"*

Composer can read the `.md`, `.docx`, `.xlsx`, `.pdf`, and `.png` files in this folder.
